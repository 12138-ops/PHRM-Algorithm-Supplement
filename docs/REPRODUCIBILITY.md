# Reproducibility guide

## Main-table protocol

[`configs/main_experiments.json`](../configs/main_experiments.json) defines the seven datasets, seeds, horizons, node counts, splits, data/support paths and dataset-specific run parameters. The paired baseline and PHRM steps are orchestrated by [`scripts/run_main.py`](../scripts/run_main.py).

The pipeline is sequential per cell:

1. Validate data and physical-support SHA256 values.
2. Fit or load the paired TQNet baseline checkpoint.
3. Fit PHRM using the same checkpoint and the dataset-specific protocol.
4. Save `result.json`, adapter weights, logs, and a run manifest with code/input/checkpoint hashes and environment versions.

The PHRM training scripts build the memory from training origins only and select checkpoints/gates on validation data. Test data is evaluated after the training choices are frozen.

## Commands

```bash
conda env create -f environment.yml
conda activate phrm-repro
python scripts/preflight.py --project-root data
python scripts/run_main.py --project-root data --dry-run
python scripts/run_main.py --project-root data
python scripts/summarize_main_results.py --project-root data
```

Use `--datasets PEMS03 --horizons 12 24 --seeds 2022` to run a smaller set of cells. The 12 required Electricity TQNet checkpoints are included under `data/checkpoints/Electricity/`. By default, the other six baseline trainers create paired checkpoints. To use the exact original baseline pairs for every dataset, provide the other 72 checkpoint files listed in the hash manifest and add `--reuse-baselines`; the runner verifies all hashes. The Electricity checkpoints are tracked; other checkpoint and result paths remain ignored by Git.

## Hashes and source provenance

`manifests/reference_artifact_hashes.csv` lists 98 artifact fingerprints recorded with the transferred experiment results: 14 data/support assets and 84 paired baseline checkpoints. The 12 Electricity checkpoints are included in this repository; the 14 data/support assets and other 72 historical checkpoints remain external. The raw server paths and private environment records were not copied. `manifests/source_inventory.csv` and `manifests/SHA256SUMS.txt` identify files included in this repository.

## Limits and reporting

The manuscript's main-results image is a reference figure, not a result generated by this package. Raw data, physical supports, and training outputs are not committed. Electricity's 12 baseline weights are included; the other 72 historical checkpoints are optional unless exact historical baseline pairs are required. A full rerun still needs the external data/support inputs. Fresh baseline training can produce small numerical differences across library, driver, and GPU versions. Keep the generated run manifest and all per-cell results with any reported reproduction.
